# Chain Helper

A ring dimension calculator for chainmaille and chain weaving.

**Live Demo:** https://mora9715.github.io/chain-helper/

## Features

- **Ring Calculator** - Enter any two of the four dimensions (Wire Diameter, Inner Diameter, Outer Diameter, Aspect Ratio) and the rest are calculated automatically
- **Unit Converter** - Convert wire gauges (AWG, SWG) and inches to millimeters

## Formulas

- Outer Diameter = Inner Diameter + 2 x Wire Diameter
- Aspect Ratio = Inner Diameter / Wire Diameter
